# Contact Form 7 - Mailchimp

A WordPress plugin that integrates Contact Form 7 (and other form plugins) with
Mailchimp, sending form submissions straight to your Mailchimp lists.

## Install
Copy the plugin folder into `wp-content/plugins/`, activate it, and configure under
the **Mailchimp** menu in wp-admin: connect your Mailchimp account (API key), then
map your form fields to a list.

## Requirements
WordPress and Contact Form 7. Tested on WordPress 7.0 / PHP 8.3.
